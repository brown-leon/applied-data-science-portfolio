# Applied Data Science Portfolio

I am a postgraduate student in Applied Data Science, building practical skills in data analysis, data preparation (ETL), and data visualisation through structured coursework and independent projects.

This portfolio presents selected work that reflects my current level of technical and analytical development. The projects emphasise transparency, reproducibility, and clear reasoning, and are intended to demonstrate how I approach data-related problems as a student developing applied skills.

The repositories below are organised by skill area.

## About Me

My academic background is in Applied Data Science and Business, with prior experience in compliance and risk-related roles. This has informed my interest in working with structured data and developing disciplined approaches to data validation and analysis.

My current focus is on exploratory analysis, data preparation workflows, and learning how to communicate analytical results through clear and effective visualisation.
